## What it is

Two Claude Code skills that turn a script and your own voice into a vertical 1080x1920 3D explainer video. Every sentence becomes its own small 3D scene built in code with three.js: a robot mascot called Bolt, a hero prop, a title plate, word captions, live counters, bursts and sound effects.

Nothing is generated by an AI video model. Claude Code writes the scenes as code, so the character stays the same in every scene, the text is always readable, every prop lands on the exact word you say, and a re-render costs nothing.

It is free and MIT licensed. The transcription runs on your own computer with Whisper, so there is no API key and no paid service. You need a paid Claude plan for Claude Code.

## Setup guide

You need macOS (tested on Apple Silicon) or Linux, Python 3.10 or newer, and ffmpeg.

1. Install:

```bash
brew install ffmpeg
git clone https://github.com/Robj1925/claude-code-3d-explainer && cd claude-code-3d-explainer
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python3 -m playwright install chromium
```

2. Make the two skills visible to Claude Code:

```bash
mkdir -p ~/.claude/skills
ln -s "$PWD/skills/3d-explainer" ~/.claude/skills/3d-explainer
ln -s "$PWD/skills/3d-explainer-script" ~/.claude/skills/3d-explainer-script
```

On Apple Silicon, `pip install mlx-whisper` makes transcription faster. It is used automatically when it is installed.

3. Write the script. In Claude Code, ask: "Write a 3D explainer script about how a password manager works." You get `script.md`: one spoken sentence per line, and a `[SCENE: ...]` cue under each one with the colour, the world, the hero prop, what happens on which word and the title.

4. Record yourself reading only the sentences, in one clean take, and save it in the same folder as `voice.wav` (or .m4a, .mp3, .mov). Pauses are fine. False starts are not removed, so record again if you stumble.

5. Ask Claude Code: "Make the 3D explainer for ./my-video." It runs these steps for you:

```bash
X=skills/3d-explainer/scripts/explainer.py
python3 $X pre   my-video     # local transcription, word timestamps, tighter pauses
python3 $X check my-video     # lint the scenes, write build/contact.jpg
python3 $X post  my-video     # render, sound effects, master, final.mp4
```

Between `pre` and `check`, Claude writes `deck.js`, one scene per sentence, timed to your words. After `check` it opens the contact sheet and fixes any prop that is cut off by the frame edge or any title that is too long.

6. Your video is `my-video/final.mp4`, mastered to about -14 LUFS, with an opening still frame you can use as the thumbnail.

Want to see the scenes before you record? `python3 $X pre my-video --from-script` makes silent timing at 165 words per minute.

## Options

- Three looks: `paper` (warm dioramas, paper titles, the default), `hud` (dark neon, glitch cuts, good for code topics) and `clay` (bright toy sets). Put `<!-- kit: hud -->` at the top of the script.
- Music: `--music your-track.mp3 --music-lu 8` puts a bed 8 LU under your voice.
- A misheard word: `pre --fix "heard=shown"`.
- A quick look at the start: `post --until 10 --preview`.

## Watch out

- Vertical 1080x1920 only for now.
- Tested on Apple Silicon Macs. Linux should work but is not tested.
- The video is only as good as the scenes Claude writes. Look at the contact sheet every time.
- Rendering runs in a headless browser on your computer. A 21 second test video rendered in 18 seconds on an M4 Mac mini; slower machines take longer.
- Claude Code needs a paid Claude plan. Everything else is free and runs locally.
